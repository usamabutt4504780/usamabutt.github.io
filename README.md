# Portfolio

This repository keeps the original standalone HTML/CSS/JavaScript portfolio at its root and adds a Next.js + Tailwind CSS version in `nextjs-portfolio/`. GitHub Pages deploys the Next.js version as static files; no server runtime is required.

## Personalize it

Both versions are personalized with Usama Ahmed's profile, experience, email, LinkedIn, and GitHub links. The technology section uses logo images from the Devicon CDN for tools listed in the supplied profile; additional enterprise platforms are listed as text. The work section presents five employer cards with animated detail panels that reveal roles, dates, and contributions on hover, keyboard focus, or selection, with an explicit close control. The standalone version initializes card selection behavior in `script.js`; the Next.js version manages card interaction in `nextjs-portfolio/app/page.tsx`. Update `index.html` and `styles.css` for the standalone version, or `nextjs-portfolio/app/page.tsx`, `nextjs-portfolio/app/globals.css`, and `nextjs-portfolio/app/layout.tsx` for the Next.js version. Update the `UA` monogram, page description, and title if you adapt it for someone else.

Both versions open with a conversation-first digital twin: visitors can select curated questions about the portfolio, get prepared answers spoken by the browser’s built-in text-to-speech voice, and see the Three.js character react with synchronized mouth movement. Voice playback can be replayed or stopped, and is not cloned from a recording. Voice availability and voice selection depend on the visitor’s browser and device. Edit `portfolioQuestions` in `nextjs-portfolio/app/page.tsx` and `questionAnswers` in `script.js` to update the questions and responses. Replies are intentionally curated rather than generated by an AI service. The standalone page loads Three.js from jsDelivr; the Next.js app bundles it from npm. WebGL is only needed for the character, and the rest of the portfolio remains usable if the 3D scene is unavailable. The page uses Google Fonts for its typography and includes local system fallbacks if the fonts cannot be reached.

The portfolio highlights **Projects & case studies** and **LLM / AI** capabilities in its technology section.

The visual theme uses a dark slate/navy monochromatic base (`#0B0F19`, `#1F2937`) with muted gray text and emerald (`#10B981`) accents.

## Standalone HTML version

Open `index.html` in a browser, or serve this folder with any static file server. This original plain HTML/CSS/JavaScript version remains available independently.

## Next.js version

```powershell
cd nextjs-portfolio
npm ci
npm run dev
```

The Next.js app uses Tailwind CSS, responsive styling, a pointer-reactive Three.js character that can wave on request, reveal animations, and reduced-motion preferences. The Three.js animation pauses when the scene is offscreen or the browser tab is hidden. To produce a static export locally, run `npm run build` from `nextjs-portfolio`; the generated static site is written to `nextjs-portfolio/out`. It can be previewed with any static file server.

## Publish with GitHub Pages

For a personal or organization root-domain site, the GitHub repository must be named `<github-owner>.github.io` (for example, `usamaahmed.github.io`). Push these files to that repository's `main` branch. The site will be published at `https://<github-owner>.github.io/`.

In the repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**. The workflow in `.github/workflows/pages.yml` installs and builds `nextjs-portfolio/`, then deploys its static `out/` files on each push to `main`. It automatically omits the repository path for `<github-owner>.github.io` sites, while retaining the repository path for project Pages sites. Find the published URL under the repository's **Settings → Pages** after the first successful deployment.
