# Portfolio

This repository keeps the original standalone HTML/CSS/JavaScript portfolio at its root and adds a Next.js + Tailwind CSS version in `nextjs-portfolio/`. GitHub Pages deploys the Next.js version as static files; no server runtime is required.

## Personalize it

Both versions are personalized with Usama Ahmed's profile, experience, email, LinkedIn, and GitHub links. The Projects & case studies section presents Simply Charge, QoPlan, STZA One Window Portal, and Descon Bidding. Simply Charge and QoPlan use live iframe previews (their sites may redirect visitors to sign-in); STZA uses an illustrative preview. Descon Bidding is an internal application, and the supplied Descon corporate site blocks iframe embedding, so the card uses an illustrative preview and a direct link to the public site. A separate employer section presents five animated employer cards with detail panels that reveal roles, dates, and contributions on hover, keyboard focus, or selection. Touch selection stays open until explicitly closed. Project and employer cards use pointer-reactive 3D tilt on hover-capable devices, respecting reduced-motion preferences. The standalone version initializes card selection behavior in `script.js`; the Next.js version manages card interaction in `nextjs-portfolio/app/page.tsx`. Update `index.html` and `styles.css` for the standalone version, or `nextjs-portfolio/app/page.tsx`, `nextjs-portfolio/app/globals.css`, and `nextjs-portfolio/app/layout.tsx` for the Next.js version. Update the `UA` monogram, page description, and title if you adapt it for someone else.

Both versions open with a conversation-first digital twin: visitors can select curated questions about the portfolio, hear a bundled recording in the same clear, professional male English voice on every device, and see the Three.js character react with synchronized mouth movement. Voice playback can be replayed or stopped; the generated voice is not a voice clone and does not use a speech service at runtime. The WAV clips live in `voice/` for the standalone site and `nextjs-portfolio/public/voice/` for the Next.js export. To update an answer, keep the corresponding entry in `portfolioQuestions` in `nextjs-portfolio/app/page.tsx`, `questionAnswers` in `script.js`, and `scripts/generate-voice.ps1` in sync, then run the PowerShell script on a Windows machine with the Microsoft David Desktop voice installed. Replies are intentionally curated rather than generated by an AI service. The standalone page loads Three.js from jsDelivr; the Next.js app bundles it from npm. WebGL is only needed for the character, and the rest of the portfolio remains usable if the 3D scene is unavailable. The page uses Google Fonts for its typography and includes local system fallbacks if the fonts cannot be reached.

The portfolio highlights **Projects & case studies** and **LLM / AI** capabilities in its technology section.

The visual theme uses a dark slate/navy monochromatic base (`#0B0F19`, `#1F2937`) with muted gray text and emerald (`#10B981`) accents.

## Standalone HTML version

Open `index.html` in a browser, or serve this folder with any static file server. This original plain HTML/CSS/JavaScript version remains available independently.

## Next.js version

```powershell
cd nextjs-portfolio
npm ci
npm run dev
```

The Next.js app uses Tailwind CSS, responsive styling, a pointer-reactive Three.js character that can wave on request, reveal animations, and reduced-motion preferences. The Three.js animation pauses when the scene is offscreen or the browser tab is hidden. To produce a static export locally, run `npm run build` from `nextjs-portfolio`; the generated static site is written to `nextjs-portfolio/out`. It can be previewed with any static file server.

## Publish with GitHub Pages

For a personal or organization root-domain site, the GitHub repository must be named `<github-owner>.github.io` (for example, `usamaahmed.github.io`). Push these files to that repository's `main` branch. The site will be published at `https://<github-owner>.github.io/`.

In the repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**. The workflow in `.github/workflows/pages.yml` installs and builds `nextjs-portfolio/`, then deploys its static `out/` files on each push to `main`. It automatically omits the repository path for `<github-owner>.github.io` sites, while retaining the repository path for project Pages sites. Find the published URL under the repository's **Settings → Pages** after the first successful deployment.
